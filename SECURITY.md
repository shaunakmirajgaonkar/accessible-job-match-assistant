# Security

## Data privacy

This application is designed for local processing. Do not commit real candidate personal data, accommodation details, contact information, resumes, or other sensitive information to Git.

Use synthetic or appropriately anonymized datasets for demonstrations.

## Reporting a security issue

Please do not publicly disclose sensitive security issues before maintainers have had an opportunity to review them.

## Secrets

No external API key is required by the default application. Never commit `.env` files containing secrets.
