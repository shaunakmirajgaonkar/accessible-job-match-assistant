# Contributing

1. Fork or clone the repository.
2. Create a feature branch.
3. Make focused changes.
4. Run the application locally.
5. Run `python3 validate_data.py`.
6. Check CSV validation and UI behavior.
7. Commit with a clear message.
8. Open a pull request describing the change.

## Development principles

- Keep processing local-first.
- Do not introduce unnecessary external APIs.
- Preserve transparent scoring.
- Validate all user-provided CSV data.
- Avoid disability-based exclusion logic.
- Do not commit secrets or private candidate information.
