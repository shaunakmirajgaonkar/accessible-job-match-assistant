# Code of Conduct

## Our commitment

We aim to make this project welcoming, respectful, inclusive, and accessible.

## Expected behavior

- Be respectful and constructive.
- Avoid discriminatory, harassing, or exclusionary behavior.
- Respect privacy and confidential information.
- Discuss technical disagreements professionally.

## Responsible use

Accessibility information in this project is intended to support workplace fit and accommodation planning. It must not be used to discriminate against people with disabilities.

## Enforcement

Project maintainers may remove contributions or participation that violate these expectations.
